# Milestone 1: Thiết lập dự án và môi trường phát triển

## Mục tiêu
Thiết lập cơ sở hạ tầng và môi trường phát triển cho toàn bộ dự án AI Chat ứng dụng Agent-to-Agent trong lĩnh vực tài chính.

## Công việc cần thực hiện
- Thiết lập cấu trúc thư mục theo yêu cầu: toàn bộ mã nguồn nằm trong thư mục `finance-agent-app`
- Cài đặt Docker và docker-compose cho môi trường phát triển
- Thiết lập hệ thống quản lý package (pnpm)
- Cấu hình TypeScript cho toàn bộ dự án
- Thiết lập ESLint và Prettier cho định dạng code chuẩn

## Kết quả mong đợi
- Dự án có cấu trúc thư mục đúng theo quy định
- Môi trường phát triển được container hóa bằng Docker
- Hệ thống build và lint hoạt động ổn định

## Công nghệ liên quan
- Docker
- Docker-compose
- pnpm
- TypeScript
- ESLint
- Prettier
