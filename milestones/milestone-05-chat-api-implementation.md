# Milestone 5: Triển khai API cho hệ thống chat

## Mục tiêu
Xây dựng API layer cho hệ thống chat giữa người dùng và AI, hỗ trợ streaming response.

## Công việc cần thực hiện
- Thiết kế REST API endpoints cho chat functionality
- Triển khai Server-Sent Events (SSE) cho streaming phản hồi AI
- Tạo middleware xử lý authentication cho chat
- Thiết kế chat session management
- Triển khai API cho portfolio detection trong hội thoại
- Tích hợp với mock AI service (sẽ thay thế sau)

## Kết quả mong đợi
- API endpoints hoạt động cho chat
- SSE streaming thành công
- Session management hoạt động ổn định
- Giao diện có thể gửi nhận tin nhắn với backend

## Công nghệ liên quan
- NestJS
- REST API
- Server-Sent Events (SSE)
- TypeScript
