# Milestone 11: Triển khai ứng dụng Desktop

## Mục tiêu
Xây dựng ứng dụng desktop bằng Electron để cung cấp trải nghiệm người dùng trên desktop.

## Công việc cần thực hiện
- Thiết lập dự án Electron với TypeScript
- Tạo cấu trúc để tái sử dụng UI từ frontend web
- Thiết kế packaging và build process cho ứng dụng desktop
- Tích hợp với backend NestJS qua HTTP/SSE
- Đảm bảo ứng dụng desktop chỉ hoạt động như client thuần, không chứa logic AI
- Tạo installer cho các nền tảng khác nhau

## Kết quả mong đợi
- Ứng dụng desktop hoạt động ổn định
- Giao diện giống hệt phiên bản web
- Tương tác với backend đúng cách
- Không chứa logic AI hay xử lý dữ liệu phức tạp

## Công nghệ liên quan
- Electron
- TypeScript
- React
- Vite
- Desktop Application Packaging
